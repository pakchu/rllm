# FGPDR-24 terminal source-support rejection

FGPDR-24 was rejected before Gross9 rows, execution prices, or post-entry
returns were opened.

The frozen sentiment source contains 1,137 daily rows from 2023-06-20 through
2026-07-31. Only 119 rows form exact three-day same-sign persistence episodes.
The preregistered 90-episode minimum therefore makes the first causal
persistence-magnitude rank available only on 2025-11-29. After the frozen
magnitude and BTC-variation gates, the primary clock contains 0/0/0/1
train/test/eval/final events, versus required minima 8/12/12/8.

Shortening the persistent-episode history, reducing the persistence length,
lowering either rank gate, changing the side, or reusing a diagnostic control
would alter the frozen candidate. FGPDR-24 is terminally rejected unchanged;
Gross9 novelty and economics remain unopened.

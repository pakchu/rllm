# HVVIXTE-24 preregistration — 2026-08-14

`HVVIXTE-24` is a daily nonlinear macro-to-BTC transition forecast. At the next
Cboe source session, it estimates the empirical probability of the next BTC sign
conditional on the latest completed VIX sign and BTC's own preceding sign. Only
transitions whose target return has already completed enter the rolling history.

The external basis is Palazzi, Raimundo Júnior, and Klotzle (2026), *From Network
Fundamentals to Macro-Financial Integration: The Evolving Predictability of
Bitcoin Returns* ([SSRN 6199098](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=6199098)).
The paper reports nonlinear macro-finance information flow to BTC as episodically
strong in stress regimes. The binary VIX conditional forecast is an untested,
fully preregistered adaptation rather than a claimed replication.

Current candidate incidence, Gross9 clocks, execution prices, returns, and PnL
remain unopened. The first failed gate is terminal and controls cannot be promoted.

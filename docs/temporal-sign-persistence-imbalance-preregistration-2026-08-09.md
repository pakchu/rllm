# TSPI-12 preregistration

TSPI-12 is frozen before source incidence, Gross9 clocks, execution prices, or
post-entry outcomes are opened. For every Wednesday 00:00 UTC decision it
partitions the preceding exact 1,440 one-minute candle-body signs into maximal
nonzero runs. It compares the sum of squared positive run lengths with the sum
of squared negative run lengths and follows the dominant side from 00:05 UTC
for twelve elapsed hours at fixed 0.5 gross.

TSPI measures the duration distribution of directional auction control. It
does not use return magnitude, ordinary body counts, one maximum run, sign
entropy, funding, flow, RV20 entry gating, or a fitted model. Those simpler
geometries are frozen diagnostic controls and cannot be promoted. Each control
uses its own exact nonzero statistic on the same source-valid Wednesday
opportunity and abstains rather than borrowing the primary side on a tie.

RV20 q90 is opened only after every full-calendar economic stage passes. The
candidate must then remain positive and beat an identical-clock,
identical-gross forced-long comparator on the causal q90 slice. Source support,
Gross9 novelty, and strict economics are terminal first-failure gates with no
weekday, window, run transform, side, entry, hold, subset, comparator, control,
or threshold repair.
